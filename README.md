# Xadrez-em-Java
Projeto de xadrez desenvolvido em Java, com foco na aplicação de conceitos de Programação Orientada a Objetos (POO), lógica de programação e estruturas de dados. O sistema faz as regras do xadrez, a movimentação das peças e a validação das jogadas, proporcionando prática no desenvolvimento de software e no aprimoramento das habilidades em Java.
